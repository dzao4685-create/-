# 熊熊角落 · 五子棋

奶油色、轻棕熊和角落小伙伴风格的五子棋小游戏。

## 在线游戏

https://xiong.dzao4685.workers.dev/

## 功能

- 15×15 自由五子棋，黑先白后，五连或以上获胜。
- 和熊熊对弈、本地双人、线上双人房间。
- 房间码和邀请链接、棋局同步、断线重连。
- 房间保留 24 小时，重新开局需双方同意。
- 手机布局与触摸落子，滑动页面不会误落子。
- 键盘方向键、回车/空格落子，可选落子音效。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| index.html | 完整页面、SVG 角色、棋盘、AI 与联机客户端 |
| worker-backend.js | D1 房间服务，服务端校验回合和落子 |
| 0000_cozy_rooms.sql | 房间数据库表 |
| build.mjs | 将页面和服务合成独立 Worker 文件 |
| xiong-worker.js | 当前 xiong 域名的转发入口及来源/邀请地址修复 |
| 玩法说明.md、联机使用说明.md | 玩法与联机说明 |

## 本地使用

直接用浏览器打开 `index.html`，或在目录启动静态 HTTP 服务。人机和本地双人模式可离线使用；线上联机需要已部署的房间服务。

## 构建完整服务

需 Node.js，无需安装第三方依赖：

```sh
npm run build
```

得到 `dist/worker.js`。部署独立服务时，需先创建 Cloudflare D1 数据库，执行 `0000_cozy_rooms.sql`，并把数据库以变量名 `DB` 绑定到 Worker。否则房间服务不可用。

迁移到新地址时，还需修改 `index.html` 中 `ONLINE_ORIGIN`，并配置 `worker-backend.js` 中允许的页面来源。构建后再部署。

## 当前线上部署关系

`xiong.dzao4685.workers.dev` 使用 `xiong-worker.js`，转发到原房间服务。页面中的邀请地址被替换为当前域名，因此创建和邀请都通过 xiong 地址进行。数据库仍由原房间服务管理；当前代理不需要单独绑定数据库。

GitHub 仓库用于保存源码；单独启用 GitHub Pages 只提供静态页面，不能承载房间数据库接口。

角色图形是页面内 SVG。仓库未附加开源许可证。


## 人机难度（2026年10月13日更新）

提供入门、标准、困难、高手、大师五档难度，不设关卡。困难、高手、大师使用最多3、4、5层限时搜索，搜索在Web Worker中运行；重新开局或悔棋会取消旧计算。实际搜索深度受设备性能与时间预算影响。
